# Doki — сайт (GitHub Pages)

Публичный статический сайт: политика конфиденциальности, условия использования и удалённый конфиг приложения. Сюда не кладём ничего секретного: всё в этой папке видно всем.

## Как опубликовать

1. Создать на GitHub **публичный** репозиторий, например `doki-site` (на бесплатном тарифе Pages работает только с публичными репозиториями; основной репозиторий с кодом остаётся приватным).
2. Скопировать в него содержимое этой папки `site/` (корнем репозитория).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
4. Адрес будет `https://<логин>.github.io/doki-site/`. Его вписать в `Project.swift` → `DOKI_SITE_URL` (пока там заглушка `example.github.io`, и приложение к ней за конфигом не ходит). Почта поддержки — `DOKI_SUPPORT_EMAIL` там же; пустая — пункт «Связаться с поддержкой» скрыт.
5. Перед публикацией заменить плейсхолдеры: `CONTACT_EMAIL`, `DEVELOPER_NAME`, `EFFECTIVE_DATE` (во всех `.html`).

Свой домен можно подключить позже (Settings → Pages → Custom domain) — адреса в приложении меняются в одном месте.

## Страницы

| Путь | Что |
|---|---|
| `privacy.html`, `ru/privacy.html` | политика конфиденциальности (App Store Connect → App Privacy → Privacy Policy URL) |
| `terms.html`, `ru/terms.html` | условия: стандартное Apple EULA + подписка, отказ от ответственности за сроки |
| `index.html` | страница поддержки (Support URL в App Store Connect) |

## Конфиг `config/v1.json`

Приложение скачивает его при запуске (не чаще раза в 12 ч), хранит последнюю версию и при отсутствии сети использует её или встроенную в сборку.

- `values` — ключ → список правил. Берётся первое правило, чьё условие `if` подходит; правило без `if` — значение по умолчанию.
- Условия `if` (все необязательны, все должны выполниться): `minVersion`, `maxVersion` (`"1.2"`), `locales` (`["ru","uk"]` — язык приложения), `countries` (`["PRT"]` — страна проживания, alpha-3), `plans` (`["free"]`/`["premium"]`), `rollout` (0–100 — процент пользователей; группа стабильна для установки).
- `data` — относительные пути к большим данным (сроки и ссылки продления). Новая версия данных — новый файл (`timing-v2.json`) и новый путь, старые не удалять, пока ими пользуются старые версии приложения.
- Неизвестные ключи приложение игнорирует; поломанный JSON — остаётся прежний конфиг.

Пример раскатки:

```json
"paywall.launch.enabled": [
  { "if": { "minVersion": "1.1", "countries": ["PRT", "ESP"], "rollout": 50 }, "value": false },
  { "value": true }
]
```

GitHub Pages кеширует файлы до 10 минут — изменения доходят не мгновенно.
